# gmt_blacklist.txt
#
# One pattern per line, same matching rule as gmt_whitelist.txt (case-insensitive
# substring/regex against gs_name). Anything matching a line here is dropped from
# the GMT even if it also matched the whitelist - the blacklist always wins.
#
# Lines starting with # and blank lines are ignored. Empty file = no exclusions.
#
# Below: adapted from the "biological blacklist" in
# Codebase/Positron/RNA-SEQ-RIG _Rebuilt/05_GMT_Generation/white-black-list.rmd
# (the non-immune candidate manifest builder) - keeps DNA-repair/cell-cycle/
# signaling/tumor-suppressor pathways out of the noise, strips immune,
# infection, tissue-specific, and disease/experimental-signature sets.
#
# NOTE: that source file's *collection*-level blacklist (GO:CC/MIR/TFT) is NOT
# here - it's collection_blacklist_patterns in Build_GMT.rmd's CONFIG block,
# since it's checked against gs_cat/gs_subcat, not gs_name, before this file
# even runs. This file is the biological (gs_name keyword) blacklist only.
